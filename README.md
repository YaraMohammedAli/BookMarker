# 📑 BookMarker

A simple and interactive web app that helps users save, visit, and delete their favorite website bookmarks — built with pure **HTML, CSS, and JavaScript**.

## 🚀 Live Demo
🔗 [View Project](https://yaramohammedali.github.io/BookMarker/)

## 🎯 Features

- Add website name and URL to your bookmark list  
- Validate inputs to ensure correct URLs  
- Display saved bookmarks dynamically in a responsive table  
- Visit websites directly from the list using “Visit” button  
- Delete bookmarks instantly with one click  
- Data persistence using **Local Storage**  

## 🛠 Technologies Used

- **HTML5** — structure  
- **CSS3** — layout and styling  
- **JavaScript (Vanilla)** — logic and DOM manipulation  
- **Local Storage API** — save data in browser  

## 💡 How It Works

1. Enter the **site name** and **URL** in the form fields.  
2. Click **Submit** to save the bookmark.  
3. The list updates automatically and shows “Visit” and “Delete” buttons.  
4. Bookmarks are stored in **localStorage**, so they remain after page reloads.
